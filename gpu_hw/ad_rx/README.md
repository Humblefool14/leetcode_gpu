# ad_rx — rasterizer RTL (atg_rx renamed, fixed, parameterized)

```
rtl/      ad_rx_pkg.sv (every width / constant, 7-character names) + 19 modules
          ad_rx_setup_uc.svh is generated by tools/ad_rx_ucode.py
fv/<m>/   FPV harness <m>_fv.sv, a SymbiYosys .sby, result.txt
sim/      ad_rx_fp_tb.sv (fp units, bit exact), ad_rx_tb.sv (direct path, end to end),
          ad_rx_warp_tb.sv (warp path, end to end), run.sh
tools/    ad_fv.py (FPV runner), fv_queue.sh, ad_rx_ucode.py, fpref.py, rx_ref.py
legacy/   rasterizer_core.sv, early_z_unit.sv (your blocks, fixed) + sim/ (their tests)
attic/    files left by an earlier interrupted session (superseded, kept for reference)
```

Hierarchy:

```
ad_rx
├── ad_rx_state                      STATE decode (once)
├── ad_rx_clip ── ad_rx_cpoly ─ fadd fmul fdiv
├── ad_rx_setup ─ ad_rx_edge ─ f2fix i2f ;  fadd fmul fdiv
├── ad_rx_scan ── ad_rx_coarse, ad_rx_cov, ad_rx_hiz, f2un ; fadd fmul i2f
├── ad_rx_frag ── ad_rx_bary ─ 4 x (fadd fmul fdiv i2f) ; i2f
└── ad_rx_order
```

Run (Yosys 0.33+, yosys-smtbmc + Yices 2, Icarus 12, Python 3 + numpy):

```
python3 tools/ad_fv.py            # every FPV job (BMC, then k-induction where 'prove')
python3 tools/ad_fv.py hiz cov    # selected jobs
sh sim/run.sh                     # fp bit-exact + both end-to-end tests
python3 tools/ad_rx_ucode.py      # after editing the setup micro-program
```

`AD_FPABS` turns the fp units into free cut-points for control-path proofs.
Mutation switches kept from atg: `MUT_COV_SKIP`, `MUT_SAMPLE_SWAP` (cov), `MUT_DZ_SIGN` (bary),
`MUT_FARCLIP`, `MUT_WCLIP` (clip).
Lint: `verilator --lint-only -Wall -Wno-WIDTH -Wno-DECLFILENAME -Wno-UNUSEDSIGNAL -Wno-UNUSEDPARAM --top-module ad_rx -Irtl rtl/*.sv` is clean.
